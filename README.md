# summario

A stateless, high-performance Go REST API microservice for automated content extraction and summarization across diverse web sources (YouTube, GitHub, Webpages, and Raw text) powered by any OpenAI-compatible LLM.

## Features

- **Universal Content Extraction**:
  - **YouTube**: Subtitle transcript extraction (JSON3) with automatic language preference.
  - **GitHub**: Repository metadata, shallow file trees, READMEs, and AI instruction files (`AGENTS.md`, `CONTEXT.md`, `CLAUDE.md`).
  - **Webpages**: Fast-path HTML text extraction via `go-trafilatura`.
  - **SPAs &amp; Reddit**: Headless browser fallback via Firecrawl (`PREFER_FIRECRAWL` or `FIRECRAWL_FALLBACK`).
  - **Raw Text**: Direct pass-through for arbitrary text.
- **Any OpenAI-Compatible LLM**: Just BYOK
- **Stateless &amp; Zero Database**: Lightweight, no external database or storage required.

## API Reference

### `POST /api/v1/tldr`

#### Request Body

```json
{
  "source": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "source_type": "auto",
  "format": "plain_text",
  "strategy": "tldr",
  "language": "en",
  "provider_config": {
    "provider": "openai",
    "api_key": "sk-...",
    "url": "https://api.openai.com/v1",
    "model": "gpt-4o-mini"
  }
}
```

- `source` *(string, required)*: Target URL or raw text.
- `source_type` *(string, default: `"auto"`)*: `auto`, `youtube`, `github`, `webpage`, `raw_text`.
- `format` *(string, default: `"markdown"`)*: `markdown`, `plain_text`.
- `strategy` *(string, default: `"tldr"`)*: `tldr` (concise), `detailed` (in-depth), `bullet_points` (list).
- `language` *(string, default: `"en"`)*: Target summary language (e.g. `en`, `ru`, `de`).
- `provider_config` *(object, optional)*: Overrides server-level LLM credentials per request.

#### Response Body (`200 OK`)

```json
{
  "summary": "This song is a pop classic expressing commitment and loyalty...",
  "title": "Song Analysis: Never Gonna Give You Up",
  "source_type": "youtube",
  "source": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "meta": {
    "language": "en",
    "format": "plain_text",
    "strategy": "tldr",
    "provider": "openai",
    "model": "gpt-4o-mini",
    "input_tokens": 705,
    "output_tokens": 118,
    "total_tokens": 823,
    "duration_ms": 1845
  }
}
```

- `summary`: Generated structured summary text.
- `title`: Contextual title generated by the LLM.
- `source_type`: Resolved source extractor type.
- `source`: Echo of the input source.
- `meta`: Execution telemetry, token usage, and end-to-end duration in ms.

#### Error Response (`4xx` / `5xx`)

```json
{
  "error": {
    "code": "INVALID_URL",
    "message": "Provided URL is invalid or malformed"
  }
}
```
